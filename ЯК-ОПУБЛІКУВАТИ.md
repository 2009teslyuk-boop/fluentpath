# Як публікувати й оновлювати FluentPath AI

## Варіант 1 — GitHub Pages (основний)

Сайт публікується автоматично з папки `docs/` гілки `main`:
**https://2009teslyuk-boop.github.io/fluentpath/**

- **Оновити сайт** = змінити файли в `docs/` і зробити commit у `main`. За 1–2 хвилини GitHub опублікує нову версію.
- Стан публікації видно у вкладці репозиторію **Actions** (запуск «pages build and deployment») або в **Settings → Pages**.
- Якщо сайт не відкривається: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/docs`, **Save**.

## Варіант 2 — Cloudflare Pages (альтернатива)

1. https://dash.cloudflare.com → **Workers & Pages → Create → Pages**.
2. Або **Connect to Git** (виберіть цей репозиторій, build command — порожньо, output directory — `docs`), або **Upload assets** і перетягніть папку `docs`.
3. Cloudflare додатково застосує заголовки безпеки з файлу `docs/_headers` (GitHub Pages їх ігнорує).

## Що отримають друзі

- Повноцінний сайт за HTTPS: тест рівня, уроки, словник, граматика, аудіювання, говоріння, письмо, Echo.
- **Профіль і прогрес кожного зберігаються в його власному браузері.** Хмарних акаунтів на сайті поки немає (з’являться з Supabase). Варто час від часу робити резервну копію: Налаштування → Дані → Експорт у JSON → «Завантажити файл».
- **Голосовий ввід** працює в браузерах із розпізнаванням мовлення (найкраще — Chrome на Mac; на iPhone — Safari), лише після згоди на мікрофон.
