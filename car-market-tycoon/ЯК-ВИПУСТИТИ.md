# Як підключити оплату і випустити гру на Roblox

Покрокова інструкція від файлу на компʼютері до гри, яка заробляє Robux. Назви кнопок у Roblox іноді трохи змінюються — якщо щось називається інакше, шукайте схоже за змістом.

---

## Крок 0. Що підготувати

- Акаунт Roblox із **підтвердженою поштою** і бажано **двофакторною автентифікацією** (Settings → Security).
- Встановлений **Roblox Studio** (create.roblox.com → Start Creating).
- Файли з репозиторію: `build/CarMarketTycoon.rbxl` (гра) і `assets/CarMeshes.obj` (3D-моделі машин і брезентів).

## Крок 1. Відкрити гру і підключити реалістичні моделі

1. Відкрийте `CarMarketTycoon.rbxl` у Studio (File → Open from File).
2. **Імпорт 3D-моделей:** вкладка **Home** (або Avatar) → **Import 3D** → виберіть `assets/CarMeshes.obj`.
   - У вікні імпорту залиште всі обʼєкти окремими деталями (не обʼєднуйте меші в один) і масштаб 1.
   - Натисніть **Import**. Зʼявиться модель із ~77 деталями (кузови, скло, дахи, брезенти + маленький `Origin`).
3. У вікні **Explorer**: правий клік на **ReplicatedStorage** → Insert Object → **Folder**, назвіть його `Assets`.
4. Перетягніть імпортовану модель у `ReplicatedStorage/Assets` і перейменуйте її на **`CarMeshes`**.
5. Натисніть **Play**: машини тепер мають гладкий кузов, а брезенти виглядають як тканина. Без цього кроку гра теж працює, але з «блочними» машинами.

## Крок 2. Вимкнути тестовий режим

У Explorer: `ReplicatedStorage → Shared → Configs → GameConfig` (подвійний клік) і змініть:

```lua
FreeLotsInStudio = false,
FreeUpgradesInStudio = false,
```

(В опублікованій грі тестовий режим і так не працює, але так ви побачите справжні ціни в Studio.)

## Крок 3. Опублікувати

1. **File → Publish to Roblox** → «Create new experience».
2. Назва (наприклад «Car Market Tycoon 🚗»), опис, жанр **Simulation / Tycoon**, пристрої: Computer, Phone, Tablet, Console.
3. Після публікації: **Home → Game Settings**:
   - **Security** → увімкніть **Enable Studio Access to API Services** (щоб у Studio працювало збереження).
   - **Places** → ваше місце → **Server Size / Max Players = 8** (на сервері 8 ділянок).
   - **Save**.

### Вставити ID у гру

У Studio: `ReplicatedStorage → Shared → Configs → MonetizationConfig`. Замініть нулі:

```lua
SpinPaid = { ProductId = 1234567890, ... },   -- ваш ID продукту
...
VIP = { GamePassId = 987654321, ... },        -- ваш ID пропуску
```

Збережіть і знову **File → Publish to Roblox**.

## Крок 5. Перевірити покупки

У Studio натисніть Play, відкрийте Мега-маркет і купіть щось. Roblox покаже **тестове вікно покупки — Robux не списуються**. Перевірте, що гроші/машина/пропуск зʼявились. В Output мають бути рядки `[Shop] ... purchased ...`.

## Крок 6. Анкета віку та сторінка гри

1. Dashboard → гра → **Audience / Maturity & Compliance Questionnaire** — пройдіть анкету (без неї гру не можна зробити публічною). У грі є платна випадкова винагорода (прокрутка колеса) — шанси показані гравцям, так і вкажіть.
2. Dashboard → гра → **Places → Configure Place / Icon & Thumbnails**: іконка 512×512 і 2–5 скріншотів 1920×1080 (зробіть у Studio: F12 або вбудований інструмент скріншотів).
3. Хороший опис: що робити в грі (лоти під брезентом, рідкісні машини, тюнінг, власний автосалон).

## Крок 7. Зробити гру публічною

Dashboard → гра → **Privacy / Permissions** → **Public** (або в Studio: Game Settings → Permissions → Public). Готово — гра в пошуку Roblox.

**Порада:** перші дні запустіть рекламу через **Ads Manager** (ads.roblox.com) хоча б на невеликий бюджет — без трафіку гру ніхто не знайде.

## Крок 8. Як отримати реальні гроші (DevEx)

1. Robux із покупок спершу «в очікуванні» (~7 днів), потім зʼявляються на балансі.
2. Ви отримуєте **70%** від ціни кожної покупки (30% — комісія Roblox).
3. **DevEx** (обмін Robux на долари): потрібно
   - вік 13+ (якщо менше 18 — оформлює один із батьків),
   - підтверджена пошта і верифікація особи,
   - мінімум **30 000 зароблених Robux**,
   - акаунт без порушень правил.
4. Подати заявку: create.roblox.com → розділ **DevEx / Earnings** → заповнити податкову форму (для України — форма W-8BEN) і платіжні дані. Курс ≈ **$0.0038 за 1 Robux**.
