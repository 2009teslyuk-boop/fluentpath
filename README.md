# FluentPath AI

**Small steps. Big fluency.** Персональна платформа для вивчення англійської від вашого поточного рівня до C1.

🌐 **Сайт:** https://2009teslyuk-boop.github.io/fluentpath/

## Що вміє

- **Тест рівня** за шістьма навичками (граматика, лексика, читання, аудіювання, письмо, говоріння) з адаптивною складністю й чесним звітом.
- **Персональний план** і щоденні уроки на 15–60 хвилин; пропущений день не обнуляє прогрес.
- **Словник** з інтервальним повторенням (SM-2): картки, spelling, вибір значення, мінітести.
- **Граматика** A1–C1 з поясненнями українською, порівняннями, типовими помилками й мінітестами.
- **Аудіювання, читання, говоріння, письмо** з перевіркою та поясненням помилок.
- **Журнал помилок** з повторенням через 1, 3, 7, 14 днів і пошуком закономірностей.
- **Echo** — анімований тьютор, який слухає, говорить і реагує на відповіді.
- Темна й світла тема, адаптація під телефон, експорт/імпорт даних.

Працює без реєстрації: прогрес зберігається в браузері. Хмарні акаунти (Supabase) — у планах.

## Структура репозиторію

| Шлях | Що це |
|---|---|
| `docs/` | Готовий сайт, який публікує GitHub Pages (один `index.html` + іконки) |
| `ARCHITECTURE.md` | Технічна архітектура: карта системи, модель даних, потоки, API, безпека |
| `ЯК-ОПУБЛІКУВАТИ.md` | Як оновлювати сайт (GitHub Pages або Cloudflare Pages) |

Назва папки `docs/` — вимога GitHub Pages; там лежить сайт, а не документація.
